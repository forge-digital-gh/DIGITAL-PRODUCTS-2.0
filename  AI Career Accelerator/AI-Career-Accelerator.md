# AI Career Accelerator

## The AI-Powered System for Building Your Career, Finding Jobs & Getting Hired

---

## START HERE

This is not just a list of AI prompts.

The **AI Career Accelerator** is a complete system for using AI to improve your career, create stronger applications, prepare for interviews, build your professional brand, and organize your job search.

### The Career Accelerator Workflow

**Discover → Prepare → Position → Apply → Interview → Follow Up → Improve → Advance**

Use the system step by step instead of randomly asking AI questions.

# CAREER DECISION FILTER

When deciding whether an opportunity is worth pursuing, score it from 1–10:

| Factor            | Score |
| ----------------- | ----: |
| Career growth     |   /10 |
| Skill development |   /10 |
| Income            |   /10 |
| Stability         |   /10 |
| Location          |   /10 |
| Work environment  |   /10 |
| Long-term value   |   /10 |

Then ask:

**Does this opportunity move me closer to my long-term goal?**

If not, understand why before accepting it.
