# AI Prompt Library — Digital Products 2.0 (50 Prompts)

Copy-paste these into ChatGPT/Claude. Replace anything in [BRACKETS]. Built around your three templates: **AUREX** (agencies/consultants), **NOVA** (fashion/product shops), **SAVOR** (restaurants/cafés).

## 1. Website Customization

### 1.1 Client Intake / Discovery
```
Act as a website copywriter conducting client discovery. I'm building a [AUREX/NOVA/SAVOR] website for a client called [BUSINESS NAME], a [TYPE OF BUSINESS] based in [LOCATION].

Ask me 8-10 sharp questions to gather everything needed to customize the site: tone/voice, target customer, services/products with prices, unique selling points, contact details, social links, and any specific pages/sections they want changed.
```

### 1.2 Full Copy — AUREX (service business)
```
Write complete website copy for an AUREX-template site for [BUSINESS NAME], a [TYPE OF BUSINESS] in [LOCATION]. Target customer: [DESCRIBE]. Tone: [e.g. premium & confident].

Give me, ready to paste into HTML: hero headline + subheadline, about section (3-4 sentences), 3-5 services with one-line descriptions and prices, 3 testimonial placeholders (marked clearly as PLACEHOLDER), FAQ (5 Q&As), footer tagline, page title + meta description (under 155 characters).
```

### 1.3 Full Copy — NOVA (product/fashion shop)
```
Write complete website copy for a NOVA-template site for [BUSINESS NAME], a [FASHION/PRODUCT] brand in [LOCATION]. Style: [e.g. streetwear / minimalist].

Give me: hero headline + subheadline, brand story (3-4 sentences), 6-8 sample products with name/description/price in [CURRENCY], nav category names, 3 review placeholders, footer tagline, page title + meta description. Flag which product names/prices also need updating in script.js.
```

### 1.4 Full Copy — SAVOR (restaurant/café)
```
Write complete website copy for a SAVOR-template site for [BUSINESS NAME], a [RESTAURANT/CAFÉ TYPE] in [LOCATION]. Cuisine/vibe: [DESCRIBE].

Give me: hero headline + subheadline, about/story section, menu (4 categories, 4-5 items each with price), opening hours block, 3 review placeholders, footer tagline, page title + meta description. Flag which menu items/prices also need updating in script.js.
```

### 1.5 Rewrite/Tighten Existing Copy
```

Rewrite it to be punchier and on-brand for [BUSINESS NAME], a [TYPE OF BUSINESS]. Keep roughly the same length so it still fits the layout. Tone: [DESCRIBE].
```
