# START HERE

Welcome to the **AI Digital Product Creator System**.

This system helps you use AI to turn an idea into a complete digital product and build a simple launch system around it.

You can use it to create:

* Ebooks
* Guides
* Checklists
* Templates
* Prompt packs
* Notion systems
* Spreadsheets
* Workbooks
* Planners
* Social media kits
* Business toolkits
* Courses
* Digital bundles
* AI-powered resources

## The Core Workflow

Follow this order:

**IDEA → RESEARCH → VALIDATE → PLAN → CREATE → IMPROVE → PACKAGE → PRICE → LAUNCH → MARKET → SELL → OPTIMIZE**

Don't try to create everything at once.

Complete one stage before moving to the next.

## 16. Create a Prompt Formula

Use this formula:

**ROLE + CONTEXT + TASK + REQUIREMENTS + OUTPUT FORMAT + QUALITY STANDARD**

Example:

```text
Act as a professional marketing strategist.

Context:
I sell [PRODUCT] to [AUDIENCE].

Task:
Create a 7-day marketing campaign.

Requirements:
Use beginner-friendly language.
Focus on organic marketing.
Include content ideas and calls to action.

Output:
Present the campaign in a table.

Quality standard:
Make every idea specific and immediately usable.
```

# PART 24 — THE GOLDEN RULES

## Rule 1

Don't create a product just because AI can create it.

Create it because someone has a problem worth solving.

## Rule 2

Don't compete by having the most pages.

Compete by creating the clearest path to the result.

## Rule 3

Don't blindly copy existing products.

Study the market, then find a better angle.

## Rule 4

Don't rely entirely on AI.

AI creates possibilities.

Human judgment creates quality.

## Rule 5

Don't launch and disappear.

Collect feedback and improve.

## Rule 6

Don't make fake promises.

Build trust.

## Rule 7

Don't create 20 products before selling one.

Get one useful product in front of real customers first.
